# 🔥 Tasty Chandigarh — Modern Japanese Fire Grill & Burger House

> **Interactive digital storefront and Robatayaki burger experience tailored for Sector 8, Chandigarh.**

---

## 🍔 Features & Modules

- **3D Exploded Burger Layer Inspector:** Interactive layer separation slider (0% to 100%) and hotspot pins for the 5:00 AM Hokkaido Shokupan bun, Binchotan charcoal-seared patty, molten volcano cheese core, and Tsukemono pickles.
- **Volcano "Cut & Pour" Split Slider:** Interactive dual-layer clip-path slider with live thermal telemetry (88.4°C molten core, 300°C Robata sear, 99.4/100 umami score).
- **Robata Fire Menu Matrix:** Complete filterable menu (Fire Burgers, Sides, Combos, Artisanal Drinks, The 7 Dip Wall) with Pure Veg & Non-Veg toggles and custom ingredient modifier sheets.
- **The 7 Dip Wall & 5-Axis Tasting Radar:** Interactive SVG Radar chart plotting *Umami, Heat, Acidity, Sweetness, and Smoke* across all 7 dips (Smoky Yuzu Tare, Sesame Toum, Truffle Miso Mayo, Ghost Togarashi, Sweet Beet Umeboshi, Smoky Wasabi Mustard, and Toasted Sesame Tahini).
- **Tactile 3D "Make It A Meal" Combo Tray Builder:** Interactive metal serving tray with real-time combo savings calculation (flat ₹99 savings).
- **Sector 8 Chandigarh Omnichannel Checkout:** 
  - **In-Car Curbside Hop** (with Car Model/Color & License Plate entry for Sector 8 Inner Market)
  - **Takeaway Express** (6-minute guarantee)
  - **Doorstep Delivery** (Chandigarh / Tricity)
  - **Dine-In Table QR**
- **Live Kitchen Dispatch Screen:** Animated 6-minute live countdown timer with 4-stage kitchen status tracking.

---

## 🛠️ Tech Stack

- **Framework:** React 18 + Vite
- **Styling:** Tailwind CSS + Custom Glassmorphism
- **Icons & Animation:** Lucide React, Canvas Confetti
- **Typography:** Syne & Inter

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/Cypher5991/FireBurgers.git

# Navigate into project directory
cd FireBurgers

# Install dependencies
npm install

# Start local development server
npm run dev
```
